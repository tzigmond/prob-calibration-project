# results/ - generated output

Everything here is produced by the `experiments/` scripts and is reproducible
from source - treat it as build output, not hand-edited.

## figures/
Plots for the report: standardized-residual histograms with fitted densities,
Q-Q plots, and tail-probability comparisons, per dataset and per model.

## tables/
The centerpiece coverage/width table (5 models × 90/95/99%, with binomial CIs and
Kupiec p-values) and its AAPL counterpart, plus the optimizer-convergence
summary. Written as CSV/Markdown for direct inclusion in the report.
