# notebooks/ — exploratory work

Scratch space for interactive exploration — not part of the reproducible
pipeline. Anything that becomes a real result should be moved into a `src/`
module (tested) and driven from an `experiments/` script.

## exploratory.ipynb
Eyeballing the data before committing to code: return distributions, kurtosis
estimates, autocorrelation of returns and of |returns| (the volatility-clustering
signal), and quick sanity plots. Use it to confirm assumptions, not to generate
final figures.
